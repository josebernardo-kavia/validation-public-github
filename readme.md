# 🐻 Project Ursus: Hello World

A simple greeting script with a heavy emphasis on North American apex predators.

## 📝 Description
This project began as a standard "Hello World" exercise, but it quickly evolved into a tribute to the family **Ursidae**. While the code simply outputs a friendly greeting to the console, the heart of this repository is dedicated to the majesty of bears.

Bears are extraordinary mammals characterized by their stocky legs, long snouts, and shaggy hair. Whether it's the **Grizzly** (*Ursus arctos horribilis*) or the **Polar Bear** (*Ursus maritimus*), these creatures represent the perfect balance of raw power and surprising intelligence. 

> **Fun Fact:** Despite their heavy build and awkward gait, some bears can run at speeds of up to **35 mph (56 km/h)**. That is significantly faster than any human developer attempting to debug code on a Friday afternoon.
